## 2024-06-02 - Command Injection using `sh -c` wrapper with Shizuku `newProcess`
**Vulnerability:** Shell-specific command injection vulnerability when combining string-based command variables with a naive `sh -c` wrapper string construction passed to Shizuku's `newProcess`.
**Learning:** `sh -c` handles parsing and executes as shell, executing inputs as code rather than simple string arguments. Because it relies on shell parsing, malicious input provided in variables can perform command injection, allowing execution of unintended commands, bypassing security configurations or checks.
**Prevention:** Avoid shell-specific string wrappers like `sh -c` where possible, or replace string commands with command arrays passed directly as program inputs `List<String>`. Also, never replace `sh -c` by simply splitting string input by spaces `command.split(" ")`. Instead, execute natively using a string array without wrappers so that arguments are processed natively as values, not interpreted code by shell environments.

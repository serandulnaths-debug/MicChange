## 2024-05-15 - Command Injection via Shizuku Shell Wrapper
**Vulnerability:** The application executed privileged commands using a shell wrapper (`sh -c`) concatenated with a user-controlled string parameter in `ShizukuCommandRunner.kt`. This creates a command injection vulnerability where a maliciously crafted package name or command string could execute arbitrary root-level shell commands.
**Learning:** Using shell wrappers (`sh -c`) with string interpolation or concatenation is unsafe for executing commands, especially when running with elevated privileges (like via Shizuku). Even internal API parameters should be considered untrusted when passed to shell executors.
**Prevention:** Always use array-based execution (`List<String>` or `Array<String>`) that passes command arguments exactly to the underlying process execution APIs (like `ProcessBuilder` or `Shizuku.newProcess`), completely bypassing shell interpretation and parameter parsing. Avoid using naive string splitting (e.g., `command.split(" ")`) as it breaks shell-specific parsing for complex arguments.

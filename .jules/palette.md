## 2026-05-24 - Improve Touch Target and Accessibility for Jetpack Compose Switches
**Learning:** In Jetpack Compose, an isolated `Switch` component often has a small touch target, and its associated text label might not be correctly linked for screen readers. This can cause frustration for users trying to tap the switch, or for users relying on accessibility tools who aren't told what the switch does.
**Action:** When creating a `Switch` with a text label, apply `Modifier.toggleable()` with `role = Role.Switch` to the parent layout (e.g., a `Row`). Then, pass the state change lambda to `toggleable` and set the inner `Switch` component's `onCheckedChange` to `null`. This expands the touch target to encompass the label and the switch together, and logically groups them for screen readers.

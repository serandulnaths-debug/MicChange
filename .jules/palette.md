## 2024-05-24 - Disable Interactive Elements When Shizuku Is Missing
**Learning:** In Jetpack Compose, when an application heavily relies on a system permission like Shizuku, interactive elements (like Switches or Buttons) that trigger actions requiring that permission should have their `enabled` state explicitly bound to the permission status. Failing to do so allows users to interact with controls that will silently fail or produce errors, leading to a confusing user experience. Furthermore, conveying why a control is disabled through appropriate accessibility mechanics (like `semantics { contentDescription = ... }`) is crucial for screen-reader users.
**Action:** When working with features that depend on a specific permission or state in Jetpack Compose, always map that state to the `enabled` property of related interactive UI elements and provide clear accessibility descriptions for the disabled state to prevent silent failures and user confusion.
